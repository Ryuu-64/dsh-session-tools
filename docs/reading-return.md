# 创建卡片返回阅读位置

关联 https://github.com/Ryuu-64/dsh-session-tools/issues/20 。当前为待验收候选，不是发布或完成声明。

## 返回语义与宿主能力

从创建卡片离开会话后，返回离开时阅读的同一段内容及可见偏移，包括当时恰好位于末尾的情况。新消息继续接收，主动去最新后才恢复跟随。只保留最近一次成功跳转：A→B→C 返回 B；失败和重复打开当前会话不替换原记录。

插件调用配套宿主的 `uiChatReading` 服务，保存不透明书签。宿主负责历史补载、原生段落定位、滚动动画、采样、尺寸变化、嵌套步骤组及焦点。恢复是带取消信号的事务；失败清理只影响本次所有权，成功后保持阅读意图。自动展开仅影响当前阅读实例，不写同会话共享折叠状态或滚动缓存。

主阅读区保留原容器身份；原生侧栏通过已有 TabOccurrence 生命周期唤回原父会话和标签，支持 Chat 重挂载。关闭、替换或重新打开的标签不能冒充原实例。未注册导航能力的自定义嵌入视图仅支持原挂载仍在的情况。书签仅驻留当前窗口，刷新和卸载后失效。

官方未修改的 RC2 尚无此服务。缺少服务时保留创建卡片跳转，明确显示“当前宿主不支持返回原阅读位置”，不提供无法兑现的返回按钮。当前验收仅使用 DSH `0.2.0-rc.2`，不使用 alpha，也不改包版本或发布 npm。

## 精确候选与 CI

[宿主源码清单](../scripts/reading-return/host/source.json)固定官方 RC2 基线 `639ed015397290b3745d163aafe02ffee4aa3f84`、目标候选 `49dee709e22189fb31bcd09c13fcc751b9ad62c1` 和完整目标 tree。[宿主补丁](../scripts/reading-return/host/native-reading.patch)由该基线重建；CI 在编译前核对 tree、文件 Git blob 和 SHA256。

`Reading return RC2` 工作流在 GitHub-hosted Ubuntu 上安装官方锁文件，编译真实宿主与客户端合约及 bundle，运行已有受影响 GUI 检查，打包 ui-chat、ui-sidebar-right、ui-subagent 三包。既有浏览器 runner 将它们装入精确 RC2 包树，再安装当前插件到临时 Web profile。安装后核对实际解析到的 bundle hash，并保存浏览器实际收到的候选脚本响应及 hash，不能只靠相同版本号认定加载成功。

场景继续使用官方 Session/JSONL 构造的合成历史，不调用模型、不读取用户 profile 或账号。报告、截图、本地构建产物和经过令牌清理的日志作为公开 CI artifact 保留 7 天。没有向 DSH 上游提交补丁或发布宿主包。

## 验收范围与剩余边界

- `npm run check` 运行已有插件 SDK/宿主、卡片身份、状态机和 DOM 边界测试；脚本化几何不代替真实 Chat 验收。
- 既有浏览器场景验证普通返回、历史补载后返回、连续跳转、换会话/刷新失效及不同会话双窗口。场景和行为断言保持不变。
- 原末尾返回后的持续/流式增长、同会话多实例隔离、折叠步骤组、侧栏定向重挂载、真实输入取消、来源删除、焦点/草稿及卸载清理，仍需完整实际验收。既有场景通过不能代表这些均通过。
- 本地完整 GUI 聚合曾有无关路径的 roster 解析和 HTTP 失败，尚未核清基线；CI 的受影响包检查不代表完整 GUI 聚合已通过。完整文档检查也仍待完成。

CI 有结果后再记录准确提交和覆盖范围；此前 Issue #20 与 PR #22 保持未完成状态。
