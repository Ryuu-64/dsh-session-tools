# 0.8.0 发布说明

`0.8.0` 增加逐会话的双向通信控制，并把通信控制与相关对话整合到 DSH 原生右侧栏。

## 安装与升级

在实际使用的 profile 安装：

```sh
dsh plugin --profile web add @ryuu-64/dsh-session-tools@0.8.0
```

安装后重启对应宿主。Node 仍需 `^22.19.0 || ^24.0.0`；CLI 插件管理需要 pnpm。完整宿主要求见[兼容说明](compatibility.md)。

## 本次改动

- 为每个普通会话增加“向其他会话发送”和“接收其他会话消息”两个独立开关；关闭发送也会阻止创建带首条消息的新会话。
- 在当前对话的原生“会话”右侧栏中同时显示通信控制和相关对话；即使没有相关对话，通信入口仍可使用。左侧会话菜单入口继续保留。
- 同一窗口中的多个入口共享权威状态；其他窗口在可见时定期重读，并在打开面板、切换会话、恢复焦点或可见性时同步。
- 保存冲突会显示最新状态；读取失败、连接断开或保存超时不会伪装成功，也不会自动重复提交不确定的写入。
- `list_sessions` 返回当前调用方到目标的通信状态；新增只读 `session_communication_status`，便于按需检查已知目标。
- `session_send` 在实际投递前重新检查双方权限。拒绝时明确表示未送达、未排队；成功消息继续通过 `messageId` 和 `session_wait` 跟踪。
- 在父会话的原生侧栏列出直接创建的普通子会话，可返回父会话、打开子会话，并由宿主管理停靠、分栏、拖动和布局持久化。

## 数据与安全边界

权限记录由宿主 storageDomain 保存；没有记录时双向开启，记录损坏或无法读取时拒绝新投递。开关只约束本插件发起的新消息，不是进程级安全隔离，也不会取消已接收的工作或影响历史读取。

兼容范围、公共右侧栏接口要求和验证边界见[兼容说明](compatibility.md)与[工具参考](tool-reference.md)。
